## Power BI Model Names

The main fact table is:

`FactSupplyChain`

Dimension tables:

`DimProduct`

`DimSupplier`

The final model uses:

- `DimProduct[SKU]` → `FactSupplyChain[SKU]`
- `DimSupplier[Supplier name]` → `FactSupplyChain[Supplier name]`

## Note

Some source fields were renamed in Power Query to make the report model more readable, such as `Revenue generated` → `Revenue` and `Stock levels` → `Stock Level`.
